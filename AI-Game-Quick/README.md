# AI梦境奇遇记 - DeepSeek文字冒险游戏

## 项目简介
这是一个基于DeepSeek API的AI原生文字冒险游戏。玩家通过输入选择，AI实时生成故事情节，创造独一无二的冒险体验。

## 如何运行
1. 直接双击打开 `index.html` 文件
2. 或使用VS Code的Live Server扩展运行

## API Key使用说明
### 获取API Key
1. 访问 [DeepSeek官网](https://platform.deepseek.com)
2. 注册账号并登录
3. 进入API Keys页面，创建新的API Key

### 使用方法
1. 游戏启动后，在输入框中粘贴您的DeepSeek API Key
2. 点击"开始游戏"按钮
3. 开始您的文字冒险之旅

### 隐私与安全
**重要承诺：**
- 🔒 **绝不存储**：您的API Key仅保存在浏览器内存中，不会写入任何持久化存储
- 🔒 **绝不发送**：Key不会发送到本项目开发者的任何服务器
- 🔒 **仅限本地**：Key仅用于您的浏览器与DeepSeek API之间的直接通信
- 🔒 **会话级保护**：关闭浏览器标签页后，Key自动清除，需要重新输入

## 技术实现
- 纯前端实现（HTML/CSS/JavaScript）
- 直接调用DeepSeek Chat API
- 响应式设计，支持桌面浏览器
